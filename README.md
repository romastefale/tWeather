# tigraoWeather

Bot de previsão do tempo para Telegram usando aiogram 3.27 + Open-Meteo.

## Recursos

- Previsão hoje, amanhã, 3, 7 e 15 dias
- Localização Telegram
- Favoritos persistentes
- Inline mode
- Cache SQLite
- Compatível com Railway
- Sem API key

## Stack

- Python 3.12
- aiogram 3.27
- aiohttp
- SQLite
- Open-Meteo

## Variáveis

```env
BOT_TOKEN=SEU_TOKEN
```

## Railway

Start command:

```bash
python -m app.main
```
